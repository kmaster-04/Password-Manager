# Usability Tasks

Please complete the following tasks using only the Quick-Start Guide provided. The observer will record how long each task takes.

**Task 1 — Create a vault**
Create a new vault protected by the master password: `TestMaster2026!`

**Task 2 — Add a credential**
Add a credential for the service `example.com`, username `alice`, with the password `SecretPass123`.

**Task 3 — Retrieve a credential**
Retrieve the password stored for `example.com` and read it aloud to the observer.

**Task 4 — Generate a random password**
Generate a 24-character random password.

**Task 5 — Lock and exit**
Lock the vault and exit the application.
